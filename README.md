# 💰 全自動記帳系統 V8.1 (Google Apps Script + iOS Shortcuts)

這是一個基於 Google Sheets 與 Google Apps Script (GAS) 開發的全自動記帳系統。整合了 iOS 捷徑 (Shortcuts) 與 Gmail 自動化，實現從「刷卡」或「現金消費」到「年度報表」的全自動化流程。

## ✨ 主要功能

### 1. 📱 iOS 捷徑整合 (Webhook)
* **即時記帳**：透過 iOS 捷徑發送 POST 請求，資料秒進 Google Sheet。
* **智慧分類**：支援傳送分類 Emoji (如 `🍔`) 或關鍵字，系統自動歸類。
* **自動防護**：內建排序防護罩，寫入後自動依日期排序，避免資料亂掉。

### 2. 📧 銀行郵件自動抓取 (Auto-Parsing)
* **支援國泰世華**：專門針對國泰世華銀行的「消費彙整通知」郵件優化。
* **V2 強力解析器**：採用逐行掃描技術，能完美解析表格型、多筆交易的帳單郵件。
* **自動化排程**：每小時自動檢查新郵件，刷卡後無需手動輸入。

### 3. 📊 總戰情室 (Unified War Room)
* **跨年度整合**：自動抓取所有年份工作表 (2024, 2025...)，合併至單一儀表板。
* **動態更新**：無論是手機記帳還是郵件抓取，完成後自動更新戰情室。
* **矩陣報表**：清楚呈現每個月、各大分類的支出狀況。

### 4. 🤖 自動化維護
* **自動開表**：新的一年第一筆資料進來時，系統自動建立新年份工作表並寫入標題。
* **重複記帳防護**：(可選) 透過邏輯檢查避免重複寫入。

## 🛠️ 安裝與設定教學

### 第一步：部署 Google Apps Script

1.  建立一個新的 Google Sheet。
2.  點擊選單列的 `擴充功能` > `Apps Script`。
3.  將本專案的 `Code.gs` 內容完整複製貼上。
4.  存檔 (Ctrl + S)。

### 第二步：發布為 Web App (給 iOS 捷徑用)

1.  在 Apps Script 介面右上角點擊 `部署` > `新增部署`。
2.  點擊齒輪圖示，選擇 `網頁應用程式`。
3.  設定如下：
    * **說明**：記帳 API
    * **執行身分**：`我` (您的 Google 帳號)
    * **誰可以存取**：`任何人` (這是必要的，因為 iOS 捷徑需要存取權)
4.  點擊 `部署`，複製產生的 **網頁應用程式網址 (Current web app URL)**。

### 第三步：設定 iOS 捷徑

在 iPhone 的「捷徑 App」中建立新捷徑，動作加入「取得 URL 內容」，設定如下：

* **URL**: (貼上剛剛複製的 Web App URL)
* **方法**: `POST`
* **標頭**: `Content-Type`: `application/json`
* **要求內文 (JSON)**:
    ```json
    {
      "date": "2026/01/17",
      "amount": "150",
      "note": "午餐",
      "type": "🍔 餐飲美食"
    }
    ```
    *(註：您可以將上面的值替換為捷徑的「詢問輸入」變數)*

### 第四步：啟動郵件抓取

1.  回到 Google Sheet，重新整理頁面。
2.  點擊上方選單出現的 `💰 記帳小幫手` > `📩 立即執行抓信 (正式)`。
3.  系統會要求授權 (Gmail 讀取權限)，請允許。
4.  完成後，系統會自動建立「每小時」的觸發條件，之後就會自動抓信了。

## ⚙️ 設定檔說明 (Configuration)

您可以在 `Code.gs` 最上方的 `CONFIG` 變數中自定義設定：

```javascript
var CONFIG = {
  WAR_ROOM_SHEET_NAME: "📊 總戰情室", 
  
  // Gmail 搜尋語法 (預設抓取國泰世華未讀通知)
  EMAIL_QUERY: 'from:cathaybk.com.tw subject:"消費彙整通知" is:unread',
  
  // 自定義分類關鍵字 (支援 Emoji)
  CATEGORIES: {
    "🍔 餐飲美食": ["餐飲", "星巴克", "麥當勞", "EAT", "FOOD"],
    "🥦 雜貨超商": ["7-ELEVEN", "全家", "全聯", "家樂福"],
    // ... 您可以自行新增或修改
  },
  DEFAULT_CATEGORY: "其他支出" 
};
